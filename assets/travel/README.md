# 足迹照片

来源：macOS「照片」相册 **A个人主页图片**。2026-10-11 导出 49 张原片；足迹页面展示 48 张，航线记录已移除。

- `originals/`：从相册导出的原始文件，以及 21 个实况照片附带的 `.mov` 文件；文件名统一为“拍摄日期_时间_地点”，实况视频与照片同名。该目录仅保存在当前项目文件夹中，由 `.gitignore` 排除，避免把约 282 MB 原片及其 EXIF 元数据直接发布。
- `web/`：48 张供网页使用的 JPEG 副本，长边最多 1200 像素，不包含原片 EXIF。
- 根目录的 `travel-photos.js`：照片与拍摄时间、位置和坐标的对应表，网页足迹图库使用该数据。

拍摄时间优先取自原片 EXIF 的 `DateTimeOriginal` 字段；不根据文件名推断。网页只展示拍摄日期，不展示具体时间、坐标或 GPS 状态。第 10、18 张的 EXIF 时间与「照片」相册显示时间不同，完整记录仍保留在 `travel-photos.js` 供核对。地图地点优先使用照片坐标。

没有 GPS 的地点与其他地点使用相同样式的地图标记。西安、华山、重庆分别使用[兵马俑坑位置](https://whc.unesco.org/fr/list/441/cartes/)、[华山景区范围](https://sthjt.shaanxi.gov.cn/sy/gs/202203/P020241011591564756796.pdf)内的参考位置和[洪崖洞位置](https://www.wikidata.org/wiki/Q32171478)。福建土楼由本人确认位于漳州，具体土楼尚未确认；地图使用[联合国教科文组织公布的漳州南靖土楼群附近区域](https://whc.unesco.org/fr/list/1113/cartes/)作为概略参考点。临近标记在视觉上分开，用细线连接到真实坐标或参考坐标，避免地图缩小时互相遮挡。这些参考标记**不代表拍摄位置**。
